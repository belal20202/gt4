# صقور الرافدين — مشروع Godot 4.3 (ثلاثي الأبعاد)

لعبة استراتيجية حربية بتضاريس 3D وإضاءة وظلال وضباب حرب، للهاتف بالوضع الأفقي.
كل الملفات نصية، فتناسب GitHub تماماً.

## التشغيل
1. نزّل **Godot 4.3** (النسخة القياسية، وليست .NET) من godotengine.org.
2. افتح Godot ← Import ← اختر ملف `project.godot`.
3. اضغط F5. (في المرة الأولى ينتظر المحرك قليلاً ليستورد الملفات.)
4. على الحاسوب: اضغط/اسحب بالفأرة، العجلة للتقريب، Q وE للتدوير، WASD للتحريك.

- شاحنة ذهب واحدة عند البداية، وتوزيع الوحدات دون تداخل.
- تصليح المباني بالذهب (زر «تصليح» يظهر عند تحديد المبنى) مع شريط الضرر فوق المبنى وفي اللوحة السفلية.

## نظام اللعب
- الذهب يأتي فقط من **شاحنات الذهب**: تذهب إلى المنجم، تحمّل، ثم تعود إلى **مقر تجميع الذهب** فيزيد رصيدك.
- يبدأ كل جيش بمقر قيادة ومقر تجميع وشاحنة واحدة. ابنِ مقرات تجميع أخرى قرب المناجم، وكل مقر جديد يُخرج شاحنة فور اكتمال بنائه.
- الأشجار والصخور والماء والآثار تمنع البناء والمرور. الجسور للمرور فقط. لا يُبنى على أرض غير مستوية.
- الخريطة 256×256 خلية (نحو 512 متراً) يحيط بها البحر. التوليد يستغرق ثوانٍ في بداية كل مباراة.
- لون الجيش يظهر على الأعلام والأسقف والأشرطة، وباقي الأشكال بألوان طبيعية.
- ٣ مستويات صعوبة: سهل، متوسط، صعب (تختلف في اقتصاد العدو وقوته ووقت أول هجوم وحجم الموجات والطيران).
- تأثيرات الضرر: شرارات وغبار عند الإصابة، دخان ثم نار على المباني المتضررة، وانهيار مع حطام عند التدمير، وسقوط الجنود وتحطم الآليات.

## الهيكل
- `scripts/data.gd` أرقام الجيوش والوحدات والمنشآت والمستويات وحجم الخريطة (عدّل التوازن من هنا)
- `scripts/main.gd` العالم والإدخال والأوامر والضباب والاقتصاد
- `scripts/terrain.gd` توليد التضاريس (نهر، جسور، جبال، واحات) + `shaders/` الخامات
- `scripts/unit.gd` `building.gd` `ai.gd` الوحدات والمباني وذكاء العدو
- `scripts/models.gd` النماذج المبنية بالكود
- `scripts/hud.gd` الواجهة، `scripts/sfx.gd` الصوت والموسيقى المولّدة
- `docs/` موقع المشروع (صفحة رئيسية + تحميل + خصوصية + نسخة المتصفح التجريبية القديمة)

## رفع الرسوميات (مهم للواقعية)
بدّل أي نموذج بملف `.glb` احترافي بوضعه في `assets/models/` بنفس الاسم:
`inf tank art heli jet` للوحدات و`hq bar fac air twr` للمباني.
لن تحتاج لتعديل أي كود. إن احتوى النموذج عقدة اسمها `Turret` أو `Rotor` فستدور تلقائياً.
أصول مجانية بترخيص CC0: Kenney.nl وQuaternius وPoly Haven.
- الخط العربي: ضع ملف خط (مثل Tajawal) باسم `assets/fonts/arabic.ttf` فيُستخدم تلقائياً.
- الصوت: ضع `click.ogg shot.ogg cannon.ogg boom.ogg music.ogg` في `assets/audio/` لاستبدال الأصوات المولّدة.

## النشر على GitHub
1. ارفع كل الملفات (بما فيها المجلد المخفي `.github`) إلى الفرع `main`.
2. Settings ← Pages ← Source: **GitHub Actions** (ينشر مجلد `docs`).
3. Actions ← **Build Android (Godot)** ← Run workflow. يخرج `rafidain-hawks.apk` في Artifacts.
4. لنشر نسخة على Releases (ويعمل رابط التحميل في الموقع): أنشئ وسماً مثل `v1.0.0`.
